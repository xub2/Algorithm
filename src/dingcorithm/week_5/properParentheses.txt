1. ( 과 ) 로 이루어진 문자열에서 ( 와 ) 의 개수가 같다면 균형잡힌 괄호 문자열
2. ( 와 )의 괄호의 짝이 맞으면 올바른 괄호 문자열

예를 들어 (()))( 는 균형잡힌 문자열 -> (.count == 3, ).count == 3
(())()는 균형잡힌 괄호 문자열이면서 동시에 올바른 괄호 문자열

이떄 ( ) 로만 이루어진 문자열 w가 균형잡힌 괄호 문자열이라면 올바른 문자열로 승격 가능
1. 입력이 빈 문자열이면 그대로 빈 문자열 반환

2. 문자열 w를 두 균형 잡힌 문자열 u , v 로 분리
2-1. 이때, u는 균형잡힌 문자열로 더이상 분화 X
2-2. v는 빈 문자열 가능

3. 문자열 u가 올바른 괄호 문자열이라면 문자열 v에 대해 1단계부터 다시 수행

4. 문자열 u가 올바른 괄호 문자열이 아니라면, 다음 4-1 과정부터 진행
4-1. 빈 문자열에 첫번째 문자로 '(' 를 추가
4-2. 문자열 v에 대해 1단계부터 재귀적으로 수행한 결과 문자열 출력
4-3. ')' 추가
4-4. u의 첫번째와 마지막 문자를 제거하고, 나머지 문자열의 괄호 방향을 뒤집어 뒤에 붙임
4-5. 생성된 문자열 반환

균형잡힌 문자열 p가 매개 변수로 주어질 때, 올바른 변환 결과 반환

"(()())()"	# -> "(()())()"
")("        # -> "()"
"()))((()"	# -> "()(())()"
